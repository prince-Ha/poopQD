# 똥 피하기 퀴즈 (poopQD)

중학교 과학 수업용 2D 모바일 웹 게임입니다.
떨어지는 단어 카드 중 **정답만 먹고**, 오답과 💩를 피하면서 개념을 반복 암기합니다.

## 게임 규칙

| 항목 | 규칙 |
| --- | --- |
| 플레이 시간 | 학생 5분 고정 (선생님은 20초 테스트 가능, 기록 안 남음) |
| 정답 | +100점, 연속 정답마다 +10점 보너스 (최대 +100) |
| 정답 먹은 뒤 | 화면에 남은 단어 카드는 모두 사라지고 다음 문제로 |
| 오답·똥 | 하트 -1 (하트 5개). 0개가 되면 하트 회복 + 500점 감점 |
| 피버타임 | 5연속 정답 → 5초 동안 똥 무적 + 캐릭터별 효과 (점수는 그대로, 오답은 하트 -1) |
| 똥 난이도 | 1분마다 1단계씩, 5단계까지 빨라지고 많아짐 |
| 쉼터 | 화면 양 끝 초록 띠에는 단어 카드도 똥도 떨어지지 않음 (문제 읽고 생각하는 안전지대) |
| 캐릭터 | 5종 중 직접 선택 또는 🎲 랜덤 |
| 조작 | ◀ ▶ 버튼 / 키보드 ← → (A, D), 일시정지 P 또는 Esc |

## 수업 준비 (선생님)

1. **구글 시트 만들기**: 게임 시작 화면 → `선생님`(비밀번호) → `시트용 스크립트 코드 복사`
   → 새 구글 시트의 [확장 프로그램] → [Apps Script]에 붙여넣기
   → `setup` 실행 → [배포] → 웹 앱 (실행: 나 / 액세스: 모든 사용자)
   → 나온 웹 앱 URL을 선생님 메뉴 `구글 시트 연결`에 붙여넣기
2. **문제 바꾸기**: 시트의 `문제` 탭(문제 · 정답 · 오답1~3)과 `설정` 탭(단원 이름)을 고치면 됩니다.
3. **수업 시작**: 선생님 메뉴 → `수업용 QR 띄우기`. QR 안에 시트 연결 정보가 들어 있어서
   학생들은 QR만 찍으면 됩니다.
4. **기록 보기**: 시트의 `기록` 탭에 학생이 게임을 마칠 때마다 한 줄씩 쌓입니다.
   랭킹은 같은 단원 안에서 이름별 최고점으로 매겨집니다.

선생님 비밀번호와 기본 시트 ID는 [`src/config.ts`](src/config.ts)에서 바꿀 수 있습니다.
시트 스크립트 원본은 [`google-apps-script/Code.gs`](google-apps-script/Code.gs)에 있습니다.

## 미리보기와 배포

1. **미리보기**: `npm run build:artifact` → `dist-artifact/poop-quiz.html` 한 장을 Claude 아티팩트로 올려서 확인
   (미리보기에서는 외부 접속이 막혀 있어 구글 시트 없이 '이 기기 기록' 모드로 동작)
2. **배포**: 마음에 들면 GitHub Actions의 `GitHub Pages 배포`를 수동 실행 (Claude에게 "배포해줘")
   → https://prince-ha.github.io/poopQD/
3. **시트 확인**: Actions의 `구글 시트 연결 확인`이 로그인 없이 시트가 열리는지 검사합니다.

## 개발

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint     # 타입 검사
npm run build    # dist/ 에 배포용 파일 생성
```

> Google AI Studio에서 만든 버전을 옮겨온 프로젝트입니다.
